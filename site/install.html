Install guides

Install, then find them in your DAW

Three steps: run the collection installer for your system, rescan plugins in your DAW, then look for Epsilon Audio in its plugin list. Every plugin also comes as VST3 and CLAP, and as an Audio Unit on macOS.

macOS

  1. Download the macOS installer (.pkg) from the download section. It runs on macOS 10.13 and later, on Apple Silicon and Intel.
  2. Open it. If macOS says it can't check the installer for malicious software, click Done, open System Settings › Privacy & Security, scroll down and click Open Anyway, then confirm. This is needed only until the installer is notarized by Apple.
  3. On Installation Type, click Customize to choose plugins and formats. VST3, Audio Unit and CLAP are selected; VST2 is there for older hosts.
  4. Install. Plugins go to /Library/Audio/Plug-Ins/ (VST3, Components, CLAP, VST) and the manuals to /Library/Documentation/Epsilon Audio.

Plugins installed this way need no Terminal commands. If you copied plugins from the individual zips instead, see "is damaged and can't be opened" below.

Windows

  1. Download the Windows installer (.exe) from the download section. It needs 64-bit Windows 10 or 11.
  2. Run it. If Windows protected your PC appears, click More info, then Run anyway. SmartScreen shows this for installers without a code-signing certificate.
  3. Pick VST3 and CLAP (recommended), Everything (adds VST2), or Custom to choose plugins one by one.
  4. Install. VST3 goes to C:\Program Files\Common Files\VST3, CLAP to C:\Program Files\Common Files\CLAP, VST2 to C:\Program Files\Steinberg\VSTPlugins.

To remove them, use Settings › Apps › Installed apps › Epsilon Audio Suite › Uninstall.

Linux

  1. Download the Linux archive (.tar.gz, x86_64) and unpack it.
  2. Run ./install.sh to install every plugin for your user (~/.vst3, ~/.clap, ~/.vst), or name the ones you want: ./install.sh Obsidian Mica.
  3. For all users, run sudo ./install.sh --system (installs to /usr/local/lib/vst3, clap and vst). ./install.sh --uninstall removes them.

Ableton Live

  1. Open Settings › Plug-Ins (Preferences in older versions).
  2. Turn on Use VST3 Plug-In System Folders. On macOS you can use the Audio Units instead: turn on Use Audio Units.
  3. Click Rescan. The plugins appear in the browser under Plug-Ins, in the Epsilon Audio folder.

Logic Pro

  1. Logic uses the Audio Unit versions and checks new ones when it starts, so quit and reopen Logic after installing.
  2. Synths (Monolith, Obsidian, Malachite) are in an instrument slot under AU Instruments › Epsilon Audio; effects are in an audio effect slot under Audio Units › Epsilon Audio.
  3. Caldera, Strata, Magma and Slate can follow MIDI: load them on an instrument track as AU MIDI-controlled Effects to play them from the keyboard.
  4. If a plugin is missing, open Logic Pro › Settings › Plug-in Manager, select it and click Reset & Rescan Selection.

FL Studio

  1. Open Options › Manage plugins and click Find installed plugins. The standard VST3 folder is searched by default.
  2. Tick the star next to the Epsilon Audio plugins you want so they show in the plugin picker and browser.
  3. Add a synth from the Channel rack (+), or an effect from a Mixer insert slot.

Reaper

  1. Open Options › Preferences › Plug-ins › VST. The default paths include the system VST3 folder; click Re-scan.
  2. For CLAP, use Plug-ins › CLAP in the same window and re-scan there.
  3. Add the plugins from the FX browser; type Epsilon in its search box to list them all.

Bitwig Studio

  1. Open Settings › Locations and check that Plug-in Locations uses the system folders (on by default).
  2. Bitwig scans on start and when folders change; use Rescan if a new plugin is missing.
  3. Use the CLAP versions where you can: Bitwig supports CLAP natively. Search the browser for Epsilon.

Troubleshooting

A plugin doesn't appear in my DAW

Check that the format your DAW uses is installed (Logic needs the Audio Unit; Ableton Live needs VST3 or AU; Bitwig and Reaper can use CLAP), that the DAW scans the standard folders listed above, and rescan. 32-bit hosts can't load the plugins; they are 64-bit only.

macOS: "is damaged and can't be opened" or "can't be verified"

macOS quarantines plugins copied from a downloaded zip until the builds are notarized. Use the collection installer, which avoids this, or clear the flag for every Epsilon Audio plugin in Terminal:

xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/*/{Monolith,Caldera,Obsidian,Strata,Basalt,Gneiss,Mica,Flint,Granite,Slate,Magma,Talc,Schist,Geode,Malachite}*
Logic Pro: "failed validation" or the plugin is greyed out

Open Logic Pro › Settings › Plug-in Manager, select the plugin and click Reset & Rescan Selection. If it still fails, reinstall it with the collection installer and restart Logic.

Windows: SmartScreen blocks the installer

Click More info, then Run anyway. It appears because the installer isn't signed with a paid code-signing certificate yet. You can check the download against the published SHA-256 checksums (below).

Linux: the plugin loads but its window stays blank

The interfaces draw with OpenGL. Install your distribution's Mesa or GPU driver packages (for example libgl1 and libx11-6 on Debian and Ubuntu) and restart the DAW.

Effects that follow MIDI don't respond

Caldera, Strata, Magma and Slate react to MIDI for key tracking, triggered envelopes and gating. Route a MIDI track to the plugin (in Logic, load it as an AU MIDI-controlled Effect), and check that its MIDI button is on.

Checking a download

Every release lists SHA256SUMS.txt. In a terminal, in the folder with your download:

shasum -a 256 -c SHA256SUMS.txt --ignore-missing     # macOS
sha256sum -c SHA256SUMS.txt --ignore-missing         # Linux
Get-FileHash .\Epsilon-Audio-Suite-*.exe              # Windows PowerShell; compare with the file
