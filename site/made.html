How they're made

Written from scratch, in the open

Every Epsilon Audio plugin is an original program with an original interface. The source code, tests and build scripts for each one are public under the MIT licence.

Clean-room designs

The series began by working through FabFilter's catalogue in release order and recreating each product's feature set as a clean-room design. Fourteen of the fifteen plugins follow a FabFilter product, from One (2002) to Pro-R (2016). The fifteenth, Malachite, starts a second line built around classic hardware instruments, beginning with the feature set of the Roland TB-303.

Each plugin was written from scratch, working only from public press releases, product descriptions, manuals and contemporary reviews. No FabFilter or Roland code, binaries, firmware, presets, artwork or trademarks were used, and every interface is an original design. Each plugin's repository keeps the notes on what it was built from.

Built on open foundations

All fifteen are built on DPF, which produces VST3, Audio Unit, CLAP and VST2 versions from one code base, and share code through epsilon-common. They use published DSP techniques: PolyBLEP oscillators, topology-preserving state-variable filters, half-band oversampling and EBU R128 loudness measurement. Every repository has a test suite, and new versions are checked to play older sessions the same way.
